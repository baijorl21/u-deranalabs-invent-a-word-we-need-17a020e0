This entry coins **pocketpat**: the panicked patting of your pockets for a phone already in your hand. `main.py` uses only the Python standard library, validates that the entry text is 1–140 characters and not only whitespace, creates the output folder named by `MAKEFUN_OUTPUT_DIR` (default `/output`), and writes the deterministic entry text to `entry.txt` inside it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
cat output/entry.txt
```
